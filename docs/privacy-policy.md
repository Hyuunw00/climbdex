# Climbdex 개인정보 처리방침

시행일: 2026-10-09

Climbdex(이하 "앱")는 클라이밍 영상을 폰 안에서 자르고, 다녀온 암장과 등반 기록을 남기는 앱입니다. 이 문서는 앱이 어떤 정보를 어디에 저장하는지 설명합니다.

## 1. 영상은 폰 밖으로 나가지 않습니다

- 고른 영상, 잘라낸 클립, 영상 분석은 전부 기기 안에서 처리됩니다. 영상 파일과 클립은 서버로 전송하지 않습니다.
- 영상의 촬영 위치는 기기 안에서 근처 암장을 찾는 데만 쓰고, 서버에는 좌표가 아니라 암장 이름(식별자)만 남습니다.

## 2. 서버에 저장하는 정보

로그인하면 아래 정보가 계정에 저장됩니다. 로그인 전에는 기기마다 임의의 익명 식별자로 저장되며, 로그인하면 같은 계정으로 합쳐집니다.

| 항목 | 내용 | 용도 |
|---|---|---|
| 계정 | Google 로그인 시 이메일, 이름, 프로필 사진 URL | 로그인, 기기 간 동기화 |
| 방문 기록 | 암장, 방문 일시 | 암장 도감 |
| 도감 사진 | 사용자가 직접 찍거나 고른 암장 사진 | 암장 도감(본인에게만 보임) |
| 등반 기록 | 암장, 난이도, 완등 여부, 클립 구간(초), 기록 근거(영상 위치·방문·직접 선택), 기기 내 영상 식별자 | 등반 기록, 난이도 표 참여 자격 |
| 영상 요약 | 영상 길이, 찾은 시도 수, 분석에 걸린 시간, 앱·분석 버전, 플랫폼 | 자동 자르기 품질 개선 |
| 난이도 표 참여 | 입력한 난이도 순서, 투표, 신고 내용 | 암장 난이도 표 |
| 암장 제보 | 제보 종류(없는 암장·폐업·이전·정보 오류), 암장, 메모 | 암장 목록 관리 |

영상 자르기는 로그인 없이도 쓸 수 있고, 이때는 위 정보를 서버에 보내지 않습니다.

## 3. 기기 권한

| 권한 | 쓰는 곳 |
|---|---|
| 사진·동영상 | 자를 영상 고르기, 잘라낸 클립 저장, 도감 사진 고르기 |
| 카메라 | 도감 사진 찍기 |
| 위치 | 근처 암장 찾기, 암장에서 방문 등록 확인 |
| 알림 | 영상 분석이 끝났을 때 알려주기 |

권한을 거부해도 앱의 다른 기능은 쓸 수 있습니다.

## 4. 보관과 삭제

- 저장한 정보는 계정을 삭제할 때까지 보관합니다.
- 앱 설정 → 계정 → 회원 탈퇴를 누르면 계정과 서버에 저장된 모든 정보(방문 기록, 도감 사진, 등반 기록, 영상 요약, 투표·제보)가 즉시 삭제됩니다.
- 로그아웃은 정보를 삭제하지 않습니다.

## 5. 처리 위탁

- 서버·데이터베이스·사진 저장소: Supabase (서울 리전)
- 로그인: Google

이 외의 제3자에게 정보를 제공하지 않으며, 광고 목적으로 쓰지 않습니다.

## 6. 변경

앱에 오류 수집이나 사용 통계 같은 기능을 추가하면 이 문서를 먼저 고치고 시행일을 바꿉니다.
