# 대구·경북 테이프 난이도 조사 결과

60곳 조사(노루클라이밍은 기지정 데이터라 제외). **테이프 색 체계를 확인한 암장은 0곳.**

- 공공 야외 암벽장·자연암장·빙벽장·리드 경기장·학교·주차장 22곳은 "none"으로 분류.
- 상업 볼더링장 ~35곳은 티스토리·디시·spiri7 도메인 제한 검색까지 했으나 암장별 색 체계 글이 없음. 대구·경북 암장 후기는 거의 네이버 블로그·인스타에만 있는 것으로 보임.
- 디시 "암장별 난이도표" 구글시트(2024)는 전국 60여 곳 중 대구는 노루클라이밍만 수록.
- 포항 4곳(스파이더·아띠·김대우·아카데미)은 디시 정보글(no=32328)로 성격(볼더링/지구력)만 확인, 색은 없음. 포항국제클라이밍센터는 볼더링 없음.
- 체인 지점(손세동 두류·칠곡, 볼더라운지 플립 대구, 뉴비 수성)은 체인 조사 결과를 그대로 쓰는 게 맞음. 뉴비 수성점은 spiri7에 페이지가 있으나 난이도표가 JS 렌더링이라 못 읽음.
- 중복 항목: 대구클라이밍센터 2건, 몬스터/몬스트, 경주클라이밍센터 2건, 김천 2건, 청송 2건.

다음 단계로는 체크인 사용자 투표(로드맵 3단계)로 채우는 수밖에 없어 보임.
