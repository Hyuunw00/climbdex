# 로드맵

## 1. 영상 자동 컷
- 입력: 사진 앱에서 영상 여러 개 선택
- 처리: 영상마다 시도 구간을 여러 개 검출. 시작 = 사람 상자가 바닥 기준선 위로 올라가는 순간, 끝 = 다시 바닥 높이로 내려오거나 화면에서 사라지는 순간
- 사용자 조절: 시작 전 N초·끝 후 N초 여유값, 구간별 시작·끝점을 미는 조절 바
- 출력: 구간마다 개별 클립으로 사진 앱에 저장
- 플랫폼: iOS 먼저. RN이면 영상 처리만 네이티브 모듈
- 시작 조건: `docs/exp-01-video-cut.md` 실험 통과

## 2. 암장 도감 (2026-09-29 착수, 서버 없이 시작)
- 초기 데이터: 카카오 로컬 API로 한 번만 시딩(`scripts/collect-gyms.mjs` → `data/gyms.json`, 529곳). 카카오 약관상 재배포 제한이 있어 이후는 우리 목록으로 관리하고 API는 안 씀. 네이버 지역검색은 호출당 5개라 수집용으로 못 씀
- 범위: 국내만. 시·도 → 구·군으로 나눠 달성률 표시(포켓몬 도감식). 종류 칸(실내·자연암벽·리드·해외)만 두고 기능은 실내만
- 이미지: 남의 로고·사진은 안 씀(인스타 프로필은 API 없음, 네이버·카카오 대표 이미지도 API 없음, 긁는 건 약관·유지보수 문제). 안 가 본 암장은 코드로 그린 회색 실루엣, 가 본 암장은 **사용자가 체크인 때 찍은 사진**이 도감 이미지. 나중에 바꿀 수 있고 그 암장 클립 썸네일로도 가능. 암장 로고는 동의받아 데이터에 채우는 자리만 둠
- 사용자 행동: 도감 탭을 열면 위치로 200m 안 암장을 찾아 "○○에 있네요 → 등록하고 사진 찍기". 암장 페이지에서 수동 등록도 가능
- 클립 연결: 영상의 촬영 시각(사진 라이브러리 creationTime)과 방문 날짜가 같으면 그 암장 페이지에 모임. 서버 불필요
- 방문·사진은 폰에 저장(문서 폴더 dex.json, gym-photos/). 서버는 띠레벨 투표 시점에 넣고 그때 올림
- 나중: 공유 카드(도감 달성률+사진 한 장 이미지), 뱃지(첫 암장·10곳·한 구 완성·같은 암장 10회), 지도 뷰. 평점·댓글은 서버 단계에서 "N회 이상 방문한 사람만" 규칙으로
- 시작 조건 변경: 원래 1번 출시 후였으나, 기능 1~2개로는 홍보가 약해 출시 전에 도감까지 붙이기로 함

## 3. 띠레벨 표
- 자격: 해당 암장 체크인 이력이 있는 사용자만, 암장당 1인 1표(변경 가능)
- 투표 방식: 절대 등급이 아니라 둘 비교("A암장 파랑 vs B암장 파랑 어디가 어렵나")
- 산출: 비교 결과로 순위 → 기준점 몇 개를 V등급에 고정해 표 생성
- 표시: 내부 저장은 V등급 범위, 화면은 사용자가 고른 기준(V·더클 띠 등)
- 초기 데이터: 개발자와 주변 클라이머가 다닌 암장으로 직접 채움
- 시작 조건: 도감에 체크인 사용자가 생긴 뒤. 홍보도 이 시점부터

## 탈락한 아이디어와 이유
- 세션 로그: 기록 자체가 부담, 본인도 안 쓸 것
- 행보드 타이머·홀드 마킹·부상 관리: 기존 앱으로 충분
- 파트너 매칭·베타 공유: 사용자 없으면 빈 앱, 한 달 안에 못 모음
- 세팅 교체 일정: 데이터 소스 없음(암장 인스타 수동 이관)
