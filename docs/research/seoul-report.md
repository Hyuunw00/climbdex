# 서울 독립 암장 테이프 난이도 조사 요약

입력 82곳 중 실제 실내 암장은 약 55곳. 나머지는 공공 실외 인공암벽장, 리드 경기장, 주차장·화장실 같은 부대시설, 협회 사무실이라 테이프 체계 대상이 아니다.

## 결과
- 테이프 색 순서 확보: 7곳 (클라이밍파크 강남·신논현·종로 3곳, 오프더월, 훅클라이밍 왕십리, 알레 혜화, 손정준 연구소)
- V등급 매핑: 0곳. 공식 V 표를 공개한 암장을 하나도 못 찾았다. 커뮤니티의 "서울숲 보라 ≈ 더클라임 빨강" 같은 상대 비교만 있었다
- 출처: 전부 blog(티스토리 후기, 디시 암벽등반갤). official 0곳

## 출처별 동작 여부
- 네이버 블로그: 크롤러 차단으로 검색·열람 불가. 한국 암장 정보의 대부분이 여기 있어 가장 큰 공백
- 인스타그램: 열람 불가
- 티스토리(jjiyo.com): 방문 후기에 색 순서를 그대로 적어 둔 글이 있어 가장 유용했다
- 디시 암벽등반 마이너갤 "암장별 난이도표": 구글 시트로 비교표를 만든다는 글. 시트 자체는 못 열었다
- spiri7.com: 암장별 난이도·실력분포 페이지가 있지만 JS 렌더링이라 본문이 안 읽힌다. 브라우저로 열면 쓸 수 있을 듯
- 공식 사이트: 더플라스틱은 DNS 실패, 나머지는 사이트 자체가 없거나 인스타만 운영

## 눈에 띄는 암장
- 클라이밍파크: 노랑→핑크→파랑→빨강→보라→갈색→회색→검정→흰색 9단계. 홀드색 무관, 테이프+숫자만 따른다고 명시된 흔치 않은 사례
- 오프더월: 빨강→주황→노랑→초록→파랑→남색→보라→회색→갈색→검정 10단계
- 훅클라이밍: 무지개 7색 + 별. 무지개 안의 순서는 통상 순서로 가정했다
- 담장(신촌·을지로): 보라 등급을 V로 세분한다는 후기만 있고 전체 순서는 못 찾음
- 홍대클라이밍은 검색에서 더클라임 홍대점으로 나왔고, 그루트클라이밍은 서울숲 성수점과 주소가 같다. 둘 다 체인 쪽 데이터와 대조 필요

## 한계
확인한 순서도 전부 후기 인용이라 confidence는 medium 이하다. 알레·손정준은 원문을 직접 못 열어 low. 네이버 블로그와 spiri7을 브라우저 도구로 열면 10곳 이상 추가로 채울 수 있을 것으로 본다.
