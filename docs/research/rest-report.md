# 인천·강원·충청·전라·제주 난이도 색 조사 요약

입력 124곳(인천·강원 42, 충청·대전·세종 34, 전라·광주·제주 48) 중 색 순서를 얻은 곳은 3곳뿐이다.

- 속초 아임낫볼더: 빨강→핑크→노랑→초록→파랑→남색→보라. 디시 후기 2건 일치, V등급 없음. confidence medium
- 전주 어센트클라이밍(만성·전북대): 디시 리뷰에 "더클 스타일, 더클보다 1~2단계 낮음"이라는 서술만 있어 더클 색 순서를 그대로 넣었다. confidence low, 실제 색은 확인 필요

나머지는 모두 tapes 빈 배열. 커뮤니티 시트 중복 5곳(클라이밍줌, 레드원 2, 픽스볼더 2)은 skip 표시했고, 야외 자연암벽·공공 인공암벽·대학·장비점·미개장·중복 주소 약 45곳은 none에 사유를 적었다. 광주(클라이븐·바위·온·빛고을·클라임라운지·인케이브), 전주(하드락·한S·바위오름·BK), 대전(어웨이크·하나클), 인천 허브, 아산 락트리는 디시 언급은 있으나 색 정보는 없어 note만 남겼다.

검색 한계: 일반 웹검색은 한국어 소규모 암장 글을 거의 못 찾았고, tistory 도메인 제한 검색은 전부 0건, 다음 검색 페이지는 빈 응답이었다. 디시 갤러리 검색은 동작하지만 답변이 댓글에 있어 본문만 읽히는 구조라 수확이 적었다. 디시 56755에 연결된 구글 시트(암장별 난이도표)는 CSV export가 400으로 막혔다. 이 시트에 '락트리' 항목이 있어 아산점 여부 확인이 필요하다.

후속 제안: 이 지역은 네이버 블로그·인스타가 주 정보원이라 다른 경로(사용자 직접 촬영, 암장 문의)가 현실적이다.
