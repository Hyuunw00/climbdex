# 실험 1. 시도 구간 자동 검출

앱 UI를 만들기 전에 검출이 되는지 노트북 스크립트로 확인한다. 실패하면 방식을 바꾸고, 통과하면 앱으로 넘어간다.

## 준비
- `samples/` 폴더에 영상 10개. 조건을 섞는다: 정면·측면, 밝은 암장·어두운 암장, 화면에 타인 통과, 완등·추락, 시작 전 오래 서 있던 것
- `samples/truth.csv`에 영상별 진짜 시작·끝 시각(초)을 손으로 기록. 한 영상에 시도가 여러 개면 행을 여러 개

## 방법
- 프레임별 사람 인식 → 상자 하단(발 위치) y좌표 시계열
- 기준선 = 영상 초반 정지 구간의 발 위치
- 시작 = 발이 기준선 위로 일정 폭 이상 올라간 첫 프레임, 끝 = 다시 기준선 근처로 내려오거나 상자가 사라진 프레임
- 짧은 흔들림은 무시(최소 지속 시간)

## 통과 기준
- 10개 중 8개 이상에서 시작·끝 모두 정답과 2초 이내
- 타인 통과 영상에서 오검출이 나면 "첫 화면에서 대상 지목" 옵션을 후속 실험으로
