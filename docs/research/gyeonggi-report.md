# 경기 암장 테이프 난이도 조사 결과

입력 102곳 중 색 체계가 일부라도 확인된 곳은 2곳뿐이다.

- 더볼더(미금): 암갤 후기에서 초록·파랑→남색→보라 순서만 확인. 전체 목록·V등급은 없음 (low)
- 에픽클라임(수원 영통): 7단계 중 5·6·7단계가 보라·흰·갈이라는 언급만 확인 (low)
- 클라임어클락·CL클라이밍(동탄): 경기남부 정리글에 언급만 있고 색 정보 없음

공공 인공암벽장·자연암벽·공원 시설 20곳은 none 처리. 시트에 이미 있는 4곳(그래비티·픽·캐치스톤·클라임어스 모란)은 스킵. 클라임어스 미사점·클라임바운스 창전점은 시트에 있는 같은 체인의 체계와 동일할 가능성이 높으니 확인 후 복사하면 된다.

나머지 70여 곳은 티스토리·디시·spiri7 도메인 제한 검색에서 자료가 나오지 않았다. 일반 웹검색은 한국어 소규모 암장 질의에 거의 무력했고, spiri7 암장 페이지는 클라이언트 렌더링이라 WebFetch로 난이도 목록이 안 보인다. 네이버 블로그·인스타가 막혀 있어 경기 소규모 암장은 이 방법으로는 한계가 크다. 암갤 '암장별 난이도표'(no=56755)에 링크된 구글 시트가 커뮤니티 시트와 같은 것인지 확인해볼 만하다.
